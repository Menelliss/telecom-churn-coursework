# Прогнозирование оттока абонентов телекоммуникационной компании

Проект посвящён прогнозированию оттока клиентов на основе показателей использования услуг. Особое внимание уделяется сравнению моделей машинного обучения и учёту дисбаланса классов.

## Цель

Построить и сравнить модели, позволяющие выявлять абонентов с повышенным риском оттока, а также определить признаки, связанные с их уходом.

## Данные

Для исследования выбран открытый набор [Iranian Churn](https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset) из UCI Machine Learning Repository.

## Основные этапы

- Исследовательский анализ и подготовка данных;
- Обучение логистической регрессии, случайного леса и градиентного бустинга;
- Сравнение качества моделей и влияния взвешивания классов;
- Исследование порога классификации;
- Интерпретация результатов и анализ ошибок.

## Инструменты

Python, Jupyter Notebook, pandas, NumPy, scikit-learn, matplotlib, seaborn.
